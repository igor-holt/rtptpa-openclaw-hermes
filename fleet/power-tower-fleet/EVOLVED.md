# Pass 1 Evolved — Compounding Test

Use this instead of speaking as the seven Pass-1 bots.

Score each candidate action.

1. Primitive: does this create something the next contributor can stand on without rereading a prompt?
2. Cost: does this lower the cost of the next operation, or only add volume?
3. Openness: what is deliberately left unfinished so the stack can still grow?
4. Fork: can this be copied without creating a second source of truth?

Verdict: `compounding` only if 1 and 2 are yes. Otherwise `additive`.
